আপনার Pairing Code

--------

WhatsApp খুলুন → Settings → Linked Devices → Link a Device → Link with phone number → এই Code প্রবেশ করান।

ব্যবহার নির্দেশিকা / Help

  1. আপনার দেশ এবং সঠিক WhatsApp Number নির্বাচন করুন।
  2. "Generate Pairing Code" বাটনে ক্লিক করুন।
  3. তৈরি হওয়া Code WhatsApp Linked Devices অপশনে গিয়ে বসান।
  4. শুধুমাত্র নিজের বা অনুমতি থাকা Account এর জন্য এই Tool ব্যবহার করুন।
  5. Code কাজ না করলে Server Status পরীক্ষা করুন এবং পুনরায় চেষ্টা করুন।
  6. Backend URL কনফিগার করা না থাকলে config.js ফাইলে নিজের Render Backend URL বসান।
